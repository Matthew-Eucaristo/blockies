Connect an agent

Claude Code (or any MCP client) can write boards and give you their links:

claude mcp add blockies -- blockies mcp

From a shell, which is what the MCP tools do too:

blockies write demo examples/checkout.blk
blockies append demo 'api -> db : one more query'

Talking on a board needs Anthropic credentials where the server runs (ANTHROPIC_API_KEY, or ant auth login). The language: /api/guide.
